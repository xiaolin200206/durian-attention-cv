# Follow-up experiment (insertion point and input resolution)

Produced by `notebooks/lfa_v2_experiment.ipynb` (equivalently `run_cv_v2.py`) on the same 20 folds,
seeds and schedule as the main experiment. Files:

- `PREREG.md`: the decision rule, written before the runs.
- `results.csv`: one row per run (200 rows).
- `preds.csv`: every test prediction.
- `numbers_v2.json`, `table6.md`: from `python analyze_v2.py`.
